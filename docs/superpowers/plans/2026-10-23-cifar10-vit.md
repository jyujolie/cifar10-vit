# CIFAR-10 ViT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a reproducible local ViT Tiny transfer-learning project for CIFAR-10.

**Architecture:** Separate environment check, training, and evaluation. Use torchvision for CIFAR-10 and timm for pretrained ViT Tiny. Track validation metrics and evaluate the held-out test set once.

**Tech Stack:** Python 3.10, PyTorch, torchvision, timm, matplotlib, scikit-learn, Git.

**Spec:** `docs/superpowers/specs/2026-10-23-cifar10-vit-design.md`

## Global Constraints

- Windows + VS Code + local NVIDIA GPU; no Colab.
- 10-class CIFAR-10; held-out test set for final evaluation.
- No fabricated results; no dataset, weights, environment or cache in Git.

## Review Focus

- CUDA unavailable: environment check reports CPU clearly; training supports an explicit device decision.
- Repeated runs: fixed seed and deterministic train/validation split.
- Test leakage: training never reads the test labels for selection.
- Interrupted training: best checkpoint and metrics can be found in ignored output directory.
- Small VRAM: conservative batch size and helpful out-of-memory guidance.
