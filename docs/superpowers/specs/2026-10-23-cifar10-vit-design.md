# CIFAR-10 ViT 项目设计

## 目标

让人工智能专业初学者在本机完成一个可复现的 CIFAR-10 图像分类项目，并用 GitHub 展示数据处理、迁移学习、训练评估和工程组织能力。

## 约束与选择

- 开发环境：Windows 上的 VS Code、Python、PyTorch、本机 NVIDIA GPU；不使用 Colab。
- 数据：CIFAR-10，训练集再划分验证集；测试集只用于最终评估。
- 模型：使用 `timm` 的预训练 ViT Tiny，将分类头改为 10 类；README 记录权重来源。
- 输出：可运行的 Python 脚本、依赖说明、README、训练指标与预测对错示例。实际指标必须来自真实运行。
- 不提交数据集、模型权重、虚拟环境或缓存到 Git。

## 实现路线

考虑过从零训练 ViT、用预训练 ViT Base 微调、用预训练 ViT Tiny 微调。用户确认预训练权重可用，且希望建立专业的本地开发流程。选 ViT Tiny 以适配本机约 8 GB 显存，同时保留完整的 PyTorch 训练循环以便学习。

## 阶段

1. 建立独立项目和 Python 环境，验证 PyTorch 能使用 GPU。
2. 实现数据、模型与训练，保存最佳验证模型。
3. 独立测试并生成图表、示例和真实结果，完善 README。
4. 用户准备好 GitHub 仓库后上传。
